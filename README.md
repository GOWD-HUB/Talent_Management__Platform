# 🎯 TalentSphere Elevate

## AI-Powered Career Development & Placement Preparation Platform

TalentSphere Elevate is a Streamlit-based application designed to help students prepare for placements by providing coding practice, resume analysis, interview preparation, GitHub portfolio review, LinkedIn profile review, and placement tracking.

---

## 🚀 Features

- 📊 College Student Dashboard
- 👤 Student Profile Management
- 📄 Resume Builder
- ✅ ATS Resume Checker
- 💻 Coding Practice
- 🎤 Mock Interviews
- 🐙 GitHub Portfolio Review
- 📄 LinkedIn PDF Review
- 📈 Placement Readiness Report
- 🎯 Job Matching
- 📚 Skill Development

---

## 🛠 Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- Plotly
- HTML & CSS
- GitHub REST API
- pypdf

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/TalentSphereElevatore.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
